

This group project was developed for a final project for ECE 210 at SCSU.
The purpose of this project was to fulfil the class requirements, but also create a useful and complete project.

For our project we created a Multi-Access door lock system which includes extra convenience and security.
It used an RFID reader, 4x4 Keypad, LCD, Solenoid Lock, and a Bluetooth Module.
